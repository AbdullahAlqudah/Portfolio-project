# Abdullah Alqudah - UI/UX Portfolio

A responsive personal portfolio website designed and developed to showcase my UI/UX design skills, projects, and professional information.

## About the Project

This portfolio was built using HTML5, CSS3, and Bootstrap 5.

The website includes the following sections:

- Navbar
- Hero Section
- About Me
- Skills
- Portfolio Projects
- Contact Form
- Footer

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Google Fonts
- Flexbox
- Bootstrap Grid System
- CSS Media Queries

## Features

- Responsive design for desktop and mobile devices
- Responsive Bootstrap navigation bar
- Internal navigation between sections
- Custom UI/UX portfolio design
- CSS hover and focus effects
- CSS animations
- Responsive project cards
- Contact form
- Custom colors using CSS variables

## Responsive Design

The website uses Bootstrap Grid and CSS Media Queries to adapt the layout to different screen sizes.

For example, the Hero section is divided into two columns on larger screens and changes its layout on smaller screens.
